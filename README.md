这是一个**仅供单机使用**的修改器。它直接修改运行中的游戏内存，不修改游戏安装目录。请在 [Releases](https://github.com/KagurazakaNatsuki/AOE2-Trainer/releases) 查看各版本的适配信息和下载文件。

### 下载和使用

1. 从 [Releases](https://github.com/KagurazakaNatsuki/AOE2-Trainer/releases) 下载与游戏版本对应的 EXE，并核对该版本发布说明中的 SHA-256。
2. 启动游戏，进入**单人战局**，再以管理员身份运行修改器。主菜单中只能检测进程，进入战局后才会显示“已连接 / 就绪”。
3. 木材、食物、黄金、石料分别输入数值并各自点击“应用”。其他功能也可用对应按钮或小键盘热键执行。
4. “瞬间研发 / 建造 / 生产”是**一次性操作**，只处理当前任务或队列；下次使用需再点一次。
5. 右上角可切换简体中文、繁體中文和 English。

| 热键 | 功能 |
| --- | --- |
| Num 1 / 2 / 3 / 4 | 分别修改木材、食物、黄金、石料 |
| Num 6 | 恢复己方单位与建筑生命值 |
| Num 7 | 瞬间研发（一次） |
| Num 8 | 瞬间建造（一次） |
| Num 9 | 瞬间生产单位（一次） |
| Num 0 | 将 AI 单位与建筑设为 1 血 |
| Num . | 游戏速度（0.5–10 倍）开关 |
| Num + | 最大人口上限设为 200 |
| Num - | 当前人口设为 0 |
| Ctrl+Shift+Home | 启用／关闭功能快捷键（默认启用） |

## Introduce

> **Unofficial project:** This independently written trainer takes inspiration from FLiNG's UI style and workflow. It is **not** an official FLiNG release and is not affiliated with, endorsed by, or sponsored by FLiNG, Microsoft, or World's Edge.

This trainer is for **single-player use only**. It modifies the running game's memory; it does not modify the game installation directory. See [Releases](https://github.com/KagurazakaNatsuki/AOE2-Trainer/releases) for version-specific compatibility and downloads.

### Download and use

1. Download the EXE matching your game version from [Releases](https://github.com/KagurazakaNatsuki/AOE2-Trainer/releases), and verify its SHA-256 against that release's notes.
2. Start the game and enter a **single-player match**, then run the trainer as administrator. Process detection in the main menu is normal; the trainer becomes ready after entering a match.
3. Enter and apply wood, food, gold, and stone amounts **separately**. Other features have individual buttons and numpad hotkeys.
4. Instant research, building, and recruitment are **one-shot actions** on current tasks or queues. Click again for later tasks.
5. Switch between Simplified Chinese, Traditional Chinese, and English in the top-right corner.

| Hotkey | Feature |
| --- | --- |
| Num 1 / 2 / 3 / 4 | Edit wood, food, gold, and stone separately |
| Num 6 | Restore health of your units and buildings |
| Num 7 | Instant research (once) |
| Num 8 | Instant buildings (once) |
| Num 9 | Instant recruit units (once) |
| Num 0 | Set AI units and buildings to 1 HP |
| Num . | Toggle game speed (0.5–10×) |
| Num + | Set maximum population cap to 200 |
| Num - | Set current population to 0 |
| Ctrl+Shift+Home | Enable/disable feature hotkeys (enabled by default) |
